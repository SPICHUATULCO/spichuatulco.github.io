# SPIC Conecta

Página de enlaces oficiales de SPIC (Bahías de Huatulco, Oaxaca).
Publicada en **https://spichuatulco.github.io** (GitHub Pages). El QR impreso apunta a esa dirección.

## Cambiar un enlace o texto
1. Abre `index.html` y busca el bloque `ENLACES DE SPIC CONECTA`.
2. Cambia solo lo que va entre comillas en `href="..."` (o el texto del botón).
3. Guarda, sube el cambio (commit + push). En 1–2 minutos queda publicado. No hay que reimprimir el QR.

## Archivos
- `index.html` — la página (estilos y enlaces dentro).
- `img/` — logo oficial, favicon e imagen para compartir en redes.
